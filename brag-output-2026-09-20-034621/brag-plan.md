# Brag Plan: Nored

## What is this app?
Nored is an offline Bluetooth mesh messenger — text, voice, photos, emergency broadcasts, and games with zero cell signal, zero Wi-Fi, zero servers.

## The angle
Show the product *working*, not describing it. Every feature scene is a captured phone-screen demo: peers appearing on Nearby, messages relaying in chat, voice transcribing on-device, an emergency alert fanning out, games over BLE. The hook is still "no signal → no problem" — then we prove it with real UI motion inside phone frames.

## Hook (first 2-3 seconds)
Full-screen "No signal." with dead signal bars — slam to full blue bars, flip to "No problem." Nored wordmark. Thesis in four words before any feature demo.

## Key moments (the middle)
- **Nearby capture:** OFFLINE MESH badge, three peers slide in (Maya Direct, Theo 1 hop, Badge-04 Direct) with signal bars — the discovery flow.
- **Chat capture:** DM thread "trailhead at dawn?" → reply sends → Queued → Relayed → Seen stamp animates — the mesh relay use case.
- **AI capture:** Voice note 0:47, tap "See transcription", text appears, French translation fades in, photo thumbnail lands — offline intelligence.
- **Alert capture:** HELP chip, injury message, broadcast ripple to peer dots — emergency mesh broadcast.
- **Games capture:** Chess / Pong / Telephone rows, tap Chess, board appears with a move — "even chess runs on Bluetooth."

## Outro / punchline
Nored logo + "Talk when the towers can't." + OFFLINE MESH badge. Hold 1.5s.

## User flow worth showing
Open Nearby (peers appear) → tap peer, send DM + voice note (key action) → message relays, transcribes, emergency reaches everyone (result). Each beat is a rendered product-video clip inside a phone frame.

## Tone
- Preset: app-store
- Creative direction: feature-demo launch film with captured product footage
- Interpretation: clean phone frames, one feature per scene, factual copy, motion proves the claim.

## Format: landscape — 1920x1080
## Duration: 20 seconds

- Accent: #2c6bed (Signal Blue)
- Text: #1b1b1b (ink), secondary #404654 (slate)
- Display font: Inter 800
- Body font: Inter 400/600
- Strongest visual element: phone UI — chat bubbles (blue mine / white theirs), peer rows with signal bars, EMERGENCY alert card.

## Share copy (draft)
Nored: offline Bluetooth mesh chat. Peers appear with no signal, messages relay phone-to-phone, voice notes transcribe on-device, and emergency alerts reach everyone. No towers required.

## Audio direction
- Role: warm bed with professional accents
- Music: happy-beats-business-moves-vol-10-by-ende-dot-app.mp3 (~110 BPM)
- Music treatment: volume 0.32, soft fade-in 0.5s, fade out last 1.5s
- Music cue guidance: preset available; strong cues at 15.82 / 18.01 / 18.55 / 20.19s; beat-grid for peer rows and game cards (every other beat ~1.1s, then hold).
- Audio-reactive treatment: subtle; phone-frame glow breathes with RMS.
- SFX posture: moderate app-store layer — card-place for peer arrivals, clicks for sends, bell for emergency, soft impact on hook/outro.
- Audio-coupled moments: bars slam, peer cards, message send, transcription reveal, emergency bell, logo payoff.
- Restraint rule: one cue per moment; music stays under SFX.
